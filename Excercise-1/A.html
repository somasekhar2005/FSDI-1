Working of HTML Lists

1. Ordered List

An ordered list displays items in a numbered sequence.

  1. Apple
  2. Banana
  3. Mango
  4. Orange

2. Unordered List

An unordered list displays items with bullet points.

  • Red
  • Green
  • Blue
  • Yellow

3. Description List

A description list contains terms and their descriptions.

HTML
